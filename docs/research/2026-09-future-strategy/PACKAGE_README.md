## Core recommendation

Preserve the simple state workflow. Develop V2’s retained events and distributed delivery around explicit persistence, ordering, recovery and access contracts. Develop V3 commands and shared operations as separate opt-in capabilities. Make configuration, failure rehearsal and diagnosis consistently useful. Let research settle consequential uncertainties without turning it into a moratorium on building.
