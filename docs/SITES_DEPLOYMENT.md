## Acceptance and rollback

For preview and production: test links, assets/fonts/logo, menus, dark mode, canonical/Open Graph URLs, 404, and expected response content types. Check `deployment.json` matches source/run. Workflows append response headers to the accepted build: nosniff, X-Frame-Options DENY, CSP frame-ancestors 'none', and strict-origin-when-cross-origin referrer policy. This limited CSP permits the existing inline theme/navigation code; it is not a full script policy. Preview also sends noindex. Blog: deployment sets **BLOG_DRAFTS=0** and never 1. Canonical/feed URLs are blog.streamotter.dev even on preview. Blog imports docs global styles, so check fonts/assets again on each candidate.
