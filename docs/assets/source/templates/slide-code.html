Browser SDK

Subscribe to a state channel.

app.ts
1import { createClient } from "streamotter/client";
2import { channelVersions, type AppChannels } from "./generated/streamotter.generated.js";
3
4const client = createClient<AppChannels>({ getToken });
5const job = client.subscribe("jobProgress", {
6  channelVersion: channelVersions.jobProgress,
7  params: { jobId: "job_1" }
8});
9job.on("data", event => render(event.data));  // full state
10job.on("state", ({ state }) => showDeliveryState(state));
11await job.ready({ timeoutMs: 30_000 });  // at the next live

What you get

A snapshot, then updates in revision order. Replace the state; don’t merge it.

A delivery state to render, so a stale view never passes as live.

Generate AppChannels with streamotter generate.
