Logo misuse

Each example below is the real file with a CSS transform or filter applied, to show what not to do. Use the files exactly as supplied, at or above their minimum size, with clear space.

Don’t recolor

No new colors, filters or tints. On dark backgrounds, switch to the -dark file instead.

Don’t stretch or squash

Scale only in proportion. Need a different shape? Pick the stacked lockup or the mark.

Don’t crop

Show the whole lockup with its clear space: the height of the wordmark’s O on every side.

Don’t rotate or tilt

The logo sits level. Let the waves and ribbons around it carry the motion.

Don’t add effects

No drop shadows, glows, outlines, bevels or blur. The brandmark is flat.

StreamOtter

Don’t type the wordmark

Never set “StreamOtter” in a font beside the mark. Use a lockup SVG, which spaces them correctly.
