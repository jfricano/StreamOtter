The one rule

The wordmark is never typeset.

As a logo, “StreamOtter” is always the wordmark or lockup SVG: its letterforms are drawn, not Figtree. In running text, write the name in the text face like any other word.

wordmark-dark.svg
StreamOttertyped in Figtree

The wordmark alone is rare: only where the mark would repeat something beside it, at 80 px wide or more, with the height of its O clear on every side. Otherwise use a lockup.
